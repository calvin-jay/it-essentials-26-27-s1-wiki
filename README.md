 # De Wereld van Cyberpunk

 > Deze wiki verzamelt de personages en locaties uit het spell cyberpunk 2077 het is developped door CD projekt Red gebaseerd op Mike Pondsmith's Cyberpunk bordspel. Het spell speelt zich af in Night City in een alternatieve versie van de Verenigde Staten waar megacorporations alle aspecten van de beschaafde mensen beheeren. De rest van de samenleving wordt gecontroleerd door bendes.
